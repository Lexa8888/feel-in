# 💕 Feel In

Приложение для пар, чтобы чувствовать друг друга на расстоянии.

## 🚀 Функции

- ✅ Статус настроения в реальном времени
- ❤️ Ежедневный ритуал: комплименты партнёру
- 📝 Дневник благодарности
- 🤝 Кнопка "Мир" для примирения
- ❓ Викторина "Мы" (60 вопросов, 1 в день)
- 🔔 Push-уведомления
- 🌓 Тёмная/светлая тема
- 🌐 Поддержка русского и английского языков
- 🔐 Защита данных (RLS в Supabase)

## 🛠 Технологии

- **Фронтенд:** React Native + Expo (Web, Android, iOS)
- **Бэкенд:** Node.js + Express + Socket.IO
- **База данных:** Supabase (PostgreSQL)
- **Деплой:** Render (сервер), EAS Build (мобильные приложения)
